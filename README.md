# Sistem-Pemesanan-Tiket-Bioskop

Untuk project UAS kali ini, saya dan teman-teman saya 
setuju untuk melanjutkan dan mengembangkan project UTS dari Raissa, 
Yaitu APLIKASI TIKETING BIOSKOP. 

Pada dasarnya sistem ini membuat pemesanan tiket bioskop untuk membantu proses pembelian tiket agar lebih cepat dan akurat.
Masalah utama adalah bagaimana menjalankan transaksi secara otomatis dari awal sampai akhir tanpa perlu perhitungan manual. 
Pertama, sistem harus bisa mengecek usia pembeli untuk memastikan mereka sudah cukup umur sebelum memesan tiket. 
Selanjutnya, sistem menghitung harga tiket berdasarkan genre film yang dipilih dan menambahkan biaya tambahan jika penonton memilih jadwal di akhir pekan.
Sistem ini juga mengalikan harga tiket dengan jumlah pesanan, serta memberikan potongan diskon secara otomatis jika total belanja mencapai batas nominal tertentu. Dengan sistem ini, kesalahan hitung dapat dihindari dan pembeli bisa menerima struk rincian pembayaran secara jelas.
